## ⚡ Selected Builds

### 01 / Academic
**A place to learn, revise, and find the next question.**

An IGCSE & A-Level learning platform connecting subject resources,
revision materials, and topic-based exam question links.

`Jekyll` `JavaScript` `MathJax` `YAML`

[Explore the platform ↗](https://academic.kcisec.site) · [Source ↗](https://github.com/KCISEastCampus/Academic)

### 02 / KCISEC Navigator
**Campus life, fewer tabs.**

A bilingual portal bringing school services, student tools,
and activities into one accessible starting point.

`HTML / CSS` `JavaScript` `Jekyll` `GitHub Pages`

[Enter the portal ↗](https://kcisec.site) · [Source ↗](https://github.com/KCISEastCampus/Pages)

### 03 / khicas-next
**Small screen. Serious mathematics.**

Work on KhiCAS for the Casio fx-CG50, built on upstream sources:
symbolic mathematics, equation conversions, and experiments
with USB connectivity.

`C / C++` `Python` `Symbolic Computing` `fx-CG50`

[Explore the project ↗](https://github.com/KCISEastCampus/khicas-next)
